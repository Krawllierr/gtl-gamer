# Fila de ideias originais

**Constituição §9.**

Toda ideia original entra aqui. Nada é descartado.

Uma ideia só sai da fila e vira projeto quando **um clone nosso já passou nos gates do §6.1**. Cada clone aprovado desbloqueia **um** slot.

> A criatividade é recompensa por competência provada, não ponto de partida.

Motivo: sem dados de retenção e sem habilidade técnica, ideia original é aposta cega com o recurso mais escasso — tempo. O clone não é o objetivo final; é como aprendemos, com risco baixo, o que faz um jogador voltar. Quando soubermos isso de verdade, estas ideias valerão muito mais.

---

## Slots desbloqueados

**0** — nenhum clone passou nos gates ainda.
